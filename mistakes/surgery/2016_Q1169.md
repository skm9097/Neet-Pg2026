## 2016_Q1169 — surgery

- **Q:** Which of the following is not true about the tests for hip instability in neonates?
- **Got wrong:** D) In barlows test examiners thumb is placed in the groin
- **Correct:** A) Ortolanis test has two parts ✅
- **Key fact:** The correct answer is A) Ortolanis test has two parts, which is incorrect because the Ortolani test is a single maneuver used to assess hip instability in neonates, where the examiner gently reduces the dislocated hip. The test is performed with the baby in a supine position and the examiner's fingers resting on the greater trochanter. In Barlow's test, the examiner's thumb is indeed placed in the groin to gently push the femoral head out of the acetabulum. The tests for hip instability are typically performed at 2-3 days of birth. 
- **Why wrong:** The student's answer, D) In barlows test examiners thumb is placed in the groin, is actually a true statement about Barlow's test, not a false one, making it an incorrect choice.
