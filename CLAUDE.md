## Project Overview

**Neet-Pg2026** is a data analysis project focused on studying and identifying patterns in NBME (National Board of Medical Examiners) question sets to support preparation for NEET-PG 2026. The repository is MIT-licensed and owned by `skm9097`.

## Current State

This repository is in its initial stage. As of the first commit, only `README.md` and `LICENSE` exist. There are no build systems, test frameworks, or established code conventions yet. Future contributors should populate this section as the project grows.

## Development Branch

Active development work goes on the `claude/add-claude-documentation-1xfan` branch. The stable branch is `main`.
