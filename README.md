## Quick start

1. **Subject revision** — open any `question-bank/subject-wise/SUBJECT.md` in GitHub.  
   Attempt each question mentally, then click the **Answer** triangle to reveal.

2. **Mock testing** — open `question-bank/2025/questions.md` (199 Qs) and time yourself.

3. **Deep-dive reading** — `notes/OBG_Concept_Book.md` teaches through embedded MCQs with full trap analysis.

4. **Mobile practice** — install the APK from `releases/` (Android, fetches latest questions from this repo).

## Exam context

- **Format:** 200 MCQs, 3.5 hours, computer-based
- **Marking:** +4 correct / −1 wrong (attempt everything where you can eliminate ≥1 option)
- **Rank-based:** percentile vs. ~2 lakh candidates
- **Trend:** Shifting toward clinical vignettes and image interpretation — application > rote recall
