# Attribution & Use Notice

## What this is

Recall-based NEET-PG/AIPGMEE previous year questions (2015–2025) compiled from multiple public sources into a self-testing Markdown question bank. These are **not** official National Board of Examinations (NBE) papers — NBE does not publicly release question papers. All questions are recall-based (reconstructed from memory by candidates post-exam) and wording, options, or answers may differ from the originals.

## Purpose

This collection exists as **personal study notes** for the repository owner's preparation for NEET-PG 2026. Files have been:

- Reformatted as collapsible-answer Markdown (`<details>`) for active self-testing
- Organised by year and by subject (19 NBE subjects)
- Annotated with real one-line mechanism/high-yield explanations for every question
- Deduplicated (0 within-file duplicate stems)

## Corrections

These recall questions should be treated as study prompts, not definitive answer keys. Cross-verify any specific drug dose, cut-off value, or clinical guideline with a current standard textbook (Harrison, Robbins, Williams Obstetrics, etc.) before exam use.
