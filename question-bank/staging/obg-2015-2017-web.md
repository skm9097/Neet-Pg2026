## Conclusion

**Zero OBG MCQs added.** No public HTML source in the allowed list exposes
question text explicitly tagged to NEET-PG/AIPGMEE 2015, 2016, or 2017 in a
form WebFetch can extract. All year-tagged corpora for that window live in
PDFs.

To honour the "Verify question is actually OBG and looks like a real PYQ"
constraint, untagged MCQs from pgblazer/medicalmcq were **not** staged here
(they would be guesses about the year). Those untagged pools are already being
mined into separate staging files (`obg-firstranker-examrace.md`,
`obg-mcq-platforms.md`, etc.) without false year attribution.
